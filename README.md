# IncidentIQ: interactive demo

A static, sample-data demo of the IncidentIQ interface: an agent investigates a production incident, proposes a remediation, and **stops for a human to approve, edit or reject it** before anything changes.

**Live demo:** https://prachics.github.io/incidentiq-demo/

Everything here is illustrative sample data. No backend, model or real incident is involved, and the numbers on the Evals tab are placeholders, not measurements. The full system (agent, retrieval, evaluation harness) is developed separately.
